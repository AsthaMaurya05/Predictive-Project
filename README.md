# Air Pollution Analysis & Prediction (Predictive Analytics Project)

This project is part of my **Predictive Analytics** subject.  
The goal is to analyse air quality data from different Indian cities and build simple predictive models to understand pollution patterns.

The project uses:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Regression Models
- Classification Models
- Clustering
- Basic Pattern/Association Analysis

Later, I will create a dashboard using **Streamlit**.
